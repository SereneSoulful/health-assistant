# 番茄钟功能实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在健康助手中新增可自定义时长的像素风番茄钟（独立置顶小窗 + 半自动阶段衔接 + 后台计时 + 单测 + 发布刷新）。

**Architecture:** 纯逻辑 `PomodoroEngine` 状态机（注入时钟）负责阶段流转；App 持有一只只睡到阶段结束的 `System.Threading.Timer` 唤醒检查；窗口可见时用 1 秒 `DispatcherTimer` 刷新显示；阶段自然结束由 `PomodoroPhaseWindow` 弹窗确认进入下一阶段。

**Tech Stack:** C# / .NET 10 / WPF / xUnit；零运行时第三方依赖（测试项目除外）。

### Task 4: PomodoroEngine 状态机（TDD）

**Files:**
- Test: `tests/健康助手.Tests/PomodoroEngineTests.cs`
- Create: `src/健康助手/Services/PomodoroEngine.cs`

**API（决策锁定，不得改名）：**

```csharp
public enum PomodoroPhase { Idle, Focus, ShortBreak, LongBreak }

public sealed class PomodoroPhaseEndedInfo
{
    public PomodoroPhase CompletedPhase { get; init; }
    public PomodoroPhase NextPhase { get; init; }
    public int CompletedFocusCount { get; init; }
}

public sealed class PomodoroEngine
{
    public PomodoroEngine(AppConfig config, Func<DateTime>? clock = null);
    public event Action? StateChanged;
    public event Action<PomodoroPhaseEndedInfo>? PhaseEnded;
    public PomodoroPhase Phase { get; }
    public DateTime? PhaseEndAt { get; }
    public bool IsPaused { get; }
    public TimeSpan Remaining { get; }
    public TimeSpan TotalDuration { get; }
    public int CompletedFocusCount { get; }
    public PomodoroPhase? NextPhase { get; }
    public void Start();
    public void Pause();
    public void Resume();
    public void Skip();
    public void StartNextPhase();
    public void SkipNextPhase();
    public void Stop();
    public void CheckPhaseEnd();
}
```

- [ ] **Step 1: 写引擎单测（假时钟）**

用例：Start 进入 Focus 且结束点 = now+25min；Focus 自然结束计数+1、下一步=短休、`PhaseEnded` 只触发一次、重复 `CheckPhaseEnd` 幂等；第 4 次专注后下一步=长休；长休结束计数归零、下一步=专注；暂停冻结剩余、恢复按新时间重算；跳过专注→立即短休且不计数；跳过短休→立即专注；停止→Idle 且清零；无待开始阶段时 `StartNextPhase` 空操作；改配置只影响之后开始的阶段。
